Retro Handheld Console

Arduino-powered mini gaming system

The Idea

I built a compact gaming system inside a pencil box — something I could carry anywhere and use anytime. The goal was simple: create a fun, portable console using basic electronics.

How It Works

The system runs on an Arduino Uno, paired with a joystick module for controls and a small OLED display for rendering games. Despite its simplicity, it delivers a smooth and responsive experience.

  • Arduino Uno
  • Joystick Module
  • 0.96" OLED Display
