The Build

This F22 Raptor model was built using a custom laser-cut frame designed for strength and lightweight performance. The goal was to create a high-speed, stable RC aircraft inspired by real-world fighter jets.

Performance Setup

Powered by a 2207 1950KV brushless motor and a 40A ESC, the plane runs on a 6S battery setup for aggressive thrust. Control is handled through ELRS, with servos managing control surfaces through pushrod mechanisms.
